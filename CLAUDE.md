# Tattoo Instagram AI agent

Контекст проекта для Claude Code. Полный план: https://claude.ai/artifact/PQs6Jv4aCAfrwFR68HLNFZ

## Что строим
AI-агент, который отвечает клиентам тату-мастера в Instagram Direct через официальный Instagram API (Instagram API with Instagram Login), Claude API и Telegram для менеджера.

## Принятые решения
- Канал: только Instagram, страница мастера. Язык по умолчанию английский, бот отвечает на языке клиента.
- Модель: Claude Opus 5.5 (`claude-opus-5-5`) с кэшированием промпта. Модель задаётся одной настройкой, чтобы при перерасходе переключиться на Sonnet 5.5 (`claude-sonnet-5-5`). Для простых FAQ можно использовать Haiku 5.5.
- Стек: Python, FastAPI, SQLite, Claude Messages API с tool use. Agent SDK, MCP и no-code не используем.
- Объём: до 30 диалогов в день.
- Оплата API: сначала тратятся $100 ежемесячных кредитов Max (организация "Oleksandr's Individual Org"), дальше докупленный баланс с автопополнением.

## Поток данных
Instagram webhook → сервер (проверка подписи, защита от дублей) → Claude API (системный промпт, база знаний, история диалога) → POST /me/messages на graph.instagram.com.

## Инструменты агента
- `escalate_to_manager(reason, urgency)`: карточка в Telegram-группу, диалог переходит в статус «менеджер».
- `create_booking_request(...)`: карточка предварительной записи в Telegram (идея, размер, место, стиль, референсы, даты), затем эскалация.
- `check_availability(...)`: ЭТАП 7, позже. Google Calendar через сервисный аккаунт. До этого этапа бот спрашивает у клиента удобные даты.

## Правила, которые обязательны
- Раскрытие «это бот» с подсказкой, что можно написать human: в начале диалога, после паузы больше 24 ч и при возврате от менеджера. Фразу добавляет код, а не модель.
- Бот отвечает только в 24-часовом окне и никогда не пишет первым. Тег HUMAN_AGENT для ответов бота запрещён.
- Теги CONFIRMED_EVENT_UPDATE, ACCOUNT_UPDATE, POST_PURCHASE_UPDATE отключены Meta с 27.04.2026.
- Не запрашивать номера карт и документы. Бронь, депозит и оплату ведёт только менеджер.
- Цены называть только диапазонами из базы знаний. Не подтверждать запись. Не давать медицинских советов.
- Сообщение менеджера из Instagram или Business Suite (приходит как эхо, отправленное не нашим приложением) ставит диалог на паузу. Бот возвращается только по кнопке «Вернуть боту» в Telegram.
- Бот ведёт только диалоги про тату: из рекламы или новые контакты, которых классификатор (Haiku 5.5) отнёс к тату. Личные контакты, диалоги, начатые мастером, и переписка до запуска бота не трогаются; их содержимое не хранится и не пересылается в Telegram.
- Удалять сообщения по webhook-уведомлению Meta. Хранить диалоги 90 дней. Не использовать данные для обучения моделей.

## Telegram
Группа с менеджером. Кнопки на карточке: «Беру диалог», «Вернуть боту», «Подтвердить запись» (с этапа 7 создаёт событие в календаре).
Также в группу приходят: ежедневная сводка с расходом в $, алерты на 50% и 80% бюджета, ошибки, напоминание об истечении токена Instagram за 7 дней.
Первую неделю работает режим одобрения: бот присылает черновик ответа с кнопками «Отправить», «Исправить», «Забрать диалог».

## Отказоустойчивость
Если Claude API вернул ошибку, кончились кредиты или истёк таймаут: клиент получает шаблонный ответ, диалог уходит менеджеру со срочной пометкой, приходит технический алерт.
Долгий токен Instagram обновляется по расписанию.

## Meta: важно
Чтобы приходили webhook-уведомления, приложение должно быть в режиме Live. Нужны ли App Review (Advanced Access для instagram_business_manage_messages) и верификация бизнеса, не подтверждено: по формулировке Meta Advanced Access нужен для чужих аккаунтов, а приложение для собственного аккаунта может хватить Standard Access. Но в другом месте Meta пишет, что для публикации (Live) приложение должно быть связано с верифицированным бизнесом. Проверяем на этапе 2: Live + сообщение с аккаунта без роли. До этого тестируем на аккаунтах с ролями в приложении. Нужна публичная страница с политикой конфиденциальности, её можно отдавать с нашего же сервера.

## Секреты
Только в переменных окружения хостинга, никогда в коде и не в чате:
ANTHROPIC_API_KEY, IG_APP_SECRET, IG_ACCESS_TOKEN, IG_VERIFY_TOKEN, TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID, TELEGRAM_WEBHOOK_SECRET, позже GOOGLE_SERVICE_ACCOUNT_JSON и GOOGLE_CALENDAR_ID.

## Открытые вопросы
- Хостинг: по умолчанию Railway или Render, решение пока не принято.
- База знаний: ждём от владельца цены, условия депозита, часы работы, стили, FAQ и 5–10 настоящих ответов мастера.
- Правила расписания: длительность сеансов, рабочие дни.
- Автовозврат бота после молчания менеджера: только по кнопке или через 24 ч (не решено).
